1. 런드렛 오픈 후 의류전달

시간당 처리량 : 1,200 개

필요 인력/대수 : 1 명

설명 : 고객의 런드렛(세탁 가방)을 열어 의류를 꺼내고 다음 공정으로 전달합니다.

2. 회원번호 스캔 & 의류 개별로딩

시간당 처리량 : 1,200 개

필요 인력/대수 : 2 명

설명 : 의류에 부착된 회원번호를 스캔하고, 한 벌씩 컨베이어 벨트에 투입합니다.

3. RFID 리딩

시간당 처리량 : 1,800 개

필요 인력/대수 : 0 대 (자동)

설명 : 컨베이어를 통과하는 개별 의류의 RFID 태그를 게이트에서 자동으로 인식합니다.

4. 의류 펼치기

시간당 처리량 : 1,000 개

필요 인력/대수 : 1 명

설명 : 자동 촬영을 위해 작업자가 의류의 앞면이 보이도록 평평하게 펼칩니다.

5. 자동 촬영

시간당 처리량 : 1,800 개

필요 인력/대수 : 0 대 (자동)

설명 : 촬영 부스에서 의류의 전체 모습을 고해상도 카메라로 자동 촬영하여 기록합니다.

6. 지정 구역 Drop (Sorter)

시간당 처리량 : 1,800 개

필요 인력/대수 : 0 대 (자동)

설명 : RFID 정보와 고객 정보를 바탕으로 의류를 분류하여 지정된 슈트(Chute)로 자동 배출합니다.

7-9. NO RFID Loop

시간당 처리량 : 300 개

필요 인력/대수 : 1 명

설명 : RFID 태그가 없는 의류는 별도 라인으로 이동하여 바코드를 부착하고, 작업자가 수동으로 RFID 태그를 삽입한 후 3번 공정으로 재투입합니다.
